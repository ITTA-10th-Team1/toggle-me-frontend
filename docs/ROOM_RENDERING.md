# 메인 방 렌더링

## 모델

- 앱 에셋: `assets/models/toggleme_room.glb` (디자이너 3차 GLB)
- 메시 12개·재질 6개·삼각형 24,772개. 내장 텍스처와 조명 없음.
- 원본 메시·재질·바이너리는 유지하고 `stand`(거울)와 `body`(냉장고)의 위치만 확정 배치로 적용.
- 노드 이름·계층·회전은 유지하여 기존 가구 터치 처리를 사용.
- 크기가 메시 정점에 반영되어 두 가구의 노드 scale은 `(1,1,1)`. 서버 배치 연동 시 이전 모델의 배율을 다시 적용하지 않아야 함.

## 화면 설정

- `RoomLightingConfig`: 환경 `legacy`, 노출 1, 그림자 강도 0.75·부드러움 1.
- 그림자는 방 전체의 접지감을 보완하며 가구별 내부 그림자를 생성하지 않음.
- 고정 카메라와 가구 터치 유지.
- 하단은 기록하기와 네 기능 버튼을 하나의 배경으로 연결.

## 확인

- 번들 렌더러에서 모델 로드, 거울·냉장고 터치 및 드래그 시 카메라 고정 확인.
- 하단 메뉴 콜백과 좁은 화면 배치를 위젯 테스트로 확인.
- Android에서는 에셋 교체 후 앱을 완전히 재실행하여 최종 화면 확인 필요.
